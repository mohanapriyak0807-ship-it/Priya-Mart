Priya Footwear & Accessories Marketplace

1. Domain

E-Commerce / Online Marketplace

2. Problem

Customers spend more time visiting different shops to find suitable footwear and accessories. Managing products, customers, stock, and orders manually is also difficult for businesses.

3. Proposed Solution

A web-based marketplace where customers can browse, search, and purchase footwear and accessories online, while admins can manage products, stock, customers, and orders.

4. Users

- Customer: Register, login, browse products, add to cart, and place orders.
- Admin: Manage products, categories, stock, and orders.

5. Core Entities

User, Product, Category, Cart, Order, Order Item, Admin

6. Main Features

- Home Page
- Registration & Login
- Product Categories
- Product Search
- Product Details
- Shopping Cart
- Order Management
- Admin Dashboard

7. Success Criteria

Customers can easily find and order products online, while admins can efficiently manage products, stock, and orders.

8. Out of Scope

International delivery, advanced AI recommendations, and multiple external seller integration.

9. Technology Stack

Frontend: HTML, CSS, JavaScript
Backend: Java, Spring Boot
Database: SQL

10. Chosen Track

Java Full Stack Development
